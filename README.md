# Advanced-Persistent-Threat

*Overview*

This is the Unity game that was made for my A Level Computer Science NEA, achieving 65/70 (A*).

It is a Tower Defence game that involves data traversing through a network. The player must strategically place cyber defences to stop malicious data entering the network. Certain types of towers are better suited to certain enemy types. The game is made to provide educational value around cybersecurity and networking.

In the game's current state, it is playable, however does not contain the necessary explanations to be a valuable learning resource, and lacks many of the planned features. Updates could be provided in the future, however further development is currently paused.

The project was designed in stages, following Analysis, Design, Implementation, then Evaluation. This was done with an Agile Development methodology, utilising 4 sprints. The whole process is heavily documented, which can be reviewed in my documentation file.

*Motivation*

As mentioned, this was a Computer Science project of mine. I chose this project due to prior experience with game development in Unity and a passion to pursue cybersecurity. My aim was to build something practical, that was directly relevant to my field of interest (cybersecurity).

*Features*

- Login system with Microsoft PlayFab
- Home page
- Currency system
- Menus for settings, modifiers, heroes, progression/unlocks
- Volume slider
- Game over screens
- Shop
- Live GUI display of lives, uptime, enemy types
- Wave system that speeds up and spawns harder enemy types
- Tower upgrades
- Tower unlock system
- Tower and enemy behaviours
- Pause button, fast-forward button
- Code uses a modular architecture

*Technology Stack*

- Unity
- C#
- Microsoft PlayFab
